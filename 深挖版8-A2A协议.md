## 写在前面：为什么 A2A 是 Agent 时代的"TCP/IP"？

**先说个真实场景**。

你的公司有 5 个 Agent：
- 客服 Agent（Dify 搭的）
- 销售 Agent（Spring AI 写的）
- 财务 Agent（阿里百炼跑的）
- 研发 Agent（自研 Python）
- HR Agent（Coze 搭的）

**某天老板说：让"销售 Agent"在客户咨询时自动调"客服 Agent"查历史工单。**

你怎么办？

**5 种方法**（每种都是屎山）：
1. 每个 Agent 暴露 REST API，挨个对接
2. 用 Kafka 做事件总线，Agent 之间互发消息
3. 写一个"中央调度器"调所有 Agent
4. 每个 Agent 复制对方的数据
5. 重写所有 Agent 统一框架

**A2A（Agent-to-Agent）就是为解决这个问题而生的。**

**类比**：
- **TCP/IP** 让不同厂商的电脑能联网
- **HTTP** 让不同服务器的网页能互通
- **A2A** 让不同厂商/不同框架的 Agent 能互操作

**A2A 是 Google 牵头、2025 年正式发布、2026 年正在被所有主流厂商采纳的协议**。

**这一篇我把 A2A 讲透**——从协议设计、核心概念、到 Java 完整实现。

## 第一部分：A2A 是什么 / 不是什么

### 1.1 A2A 的官方定义

**Google A2A 协议（2025 年发布）**：
> **An open protocol enabling communication and interoperability between opaque Agentic Applications.**

翻译：**让不同的、不透明的 Agent 应用能相互通信和互操作。**

**关键 3 个词**：
- **Open（开放）**——开源协议，不绑定任何厂商
- **Opaque（不透明）**——Agent 内部怎么实现的不重要，**只暴露"能干什么"**
- **Interoperability（互操作）**——能相互调用、相互协作

### 1.2 A2A 不是什么

| 不是 | 是 |
|---|---|
| **不是 Agent 框架**（不替代 LangGraph / Spring AI）| 是 **Agent 之间的通信协议** |
| **不是 Function Calling**（不替代工具调用）| 是 **Agent 之间的对话协议** |
| **不是数据格式标准**（不替代 JSON Schema）| 是 **Agent 协作的语义标准** |
| **不是中心化调度**（不是 Master-Worker）| 是 **去中心化的对等通信** |

### 1.3 A2A vs MCP 区别（容易混）

| 维度 | A2A | MCP |
|---|---|---|
| **定位** | Agent ↔ Agent | Agent ↔ Tool |
| **发起方** | Google + Linux 基金会 | Anthropic |
| **发布** | 2025 年 4 月 | 2024 年 11 月 |
| **状态** | 标准制定中（v0.2） | 已被广泛采纳 |
| **通信** | JSON-RPC over HTTP/SSE | JSON-RPC over stdio/HTTP |
| **场景** | 跨厂商 Agent 协作 | 工具/资源访问 |

**用一句话区分**：
- **MCP**：Agent 用工具（A → T）
- **A2A**：Agent 找 Agent（A → A）

详见深挖版 9（MCP）。

## 第二部分：A2A 核心概念

### 2.1 四大核心对象

```
┌─────────────────────────────────────────────────┐
│ 1. Agent Card（Agent 名片）                       │
│    → 描述 Agent 能力、技能、联系方式               │
│    → 公开的，任何人都能查                          │
└─────────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────────┐
│ 2. Task（任务）                                   │
│    → 一次协作的"会话"                             │
│    → 有 ID、有状态、有生命周期                     │
└─────────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────────┐
│ 3. Message（消息）                                │
│    → 任务里的"对话"                               │
│    → 带 role、parts、metadata                     │
└─────────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────────┐
│ 4. Artifact（产物）                               │
│    → 任务完成后的产出                              │
│    → 文件、报告、数据、结果                        │
└─────────────────────────────────────────────────┘
```

### 2.2 Agent Card 详解

**Agent Card = Agent 的"名片 + 简历"**。

**它告诉别人**：
- 我叫什么
- 我能做什么
- 怎么联系我
- 我支持什么认证
- 我有什么限制

**JSON 格式**：

```json
{
  "name": "销售助手 Agent",
  "description": "专业的销售支持 Agent，能查 CRM、查客户历史、生成报价单",
  "url": "https://sales-agent.company.com",
  "version": "1.2.0",
  "provider": {
    "organization": "ACME Corp",
    "url": "https://acme.com"
  },
  "skills": [
    {
      "id": "query_customer",
      "name": "查询客户信息",
      "description": "根据客户 ID 或姓名查询客户档案、历史订单、合同信息",
      "inputSchema": {
        "type": "object",
        "properties": {
          "customer_id": { "type": "string", "description": "客户 ID" },
          "include_orders": { "type": "boolean", "default": true }
        }
      },
      "outputSchema": {
        "type": "object",
        "properties": {
          "customer": { "type": "object" },
          "orders": { "type": "array" }
        }
      },
      "examples": [
        {
          "input": { "customer_id": "C-001" },
          "output": { "customer": {...} }
        }
      ]
    },
    {
      "id": "generate_quote",
      "name": "生成报价单",
      "description": "根据产品和数量生成 PDF 报价单"
    }
  ],
  "authentication": {
    "type": "oauth2",
    "authorizationUrl": "https://sales-agent.company.com/oauth/authorize",
    "tokenUrl": "https://sales-agent.company.com/oauth/token",
    "scopes": ["read:customer", "write:quote"]
  },
  "capabilities": {
    "streaming": true,
    "pushNotifications": true,
    "stateTransitionHistory": true
  },
  "defaultInputModes": ["text", "file"],
  "defaultOutputModes": ["text", "file", "json"]
}
```

**关键字段**：
- **skills**：声明能做的事（每个 skill 有 input/output schema）
- **examples**：示例调用（让 LLM 更好理解）
- **authentication**：认证方式
- **capabilities**：能力声明（是否支持流式 / 推送）

### 2.3 Task 生命周期

```
   created → submitted → working → [input-required] → completed/failed/canceled
                ↑                ↓                        ↓
                └──── (用户补充信息) ←──────────────────────┘
```

**Task 状态机**：

| 状态 | 含义 |
|---|---|
| `created` | 任务已创建，Agent 还没开始 |
| `submitted` | 任务已提交给 Agent |
| `working` | Agent 正在处理 |
| `input-required` | Agent 需要更多信息（要问用户问题）|
| `completed` | 任务完成，有 Artifact |
| `failed` | 任务失败，有 error |
| `canceled` | 任务被取消 |

**Task 对象示例**：

```json
{
  "id": "task-abc123",
  "contextId": "ctx-001",
  "status": {
    "state": "working",
    "message": "正在查询客户信息...",
    "timestamp": "2026-06-10T14:23:45Z"
  },
  "history": [
    { "state": "created", "timestamp": "..." },
    { "state": "submitted", "timestamp": "..." },
    { "state": "working", "timestamp": "..." }
  ],
  "artifacts": [],
  "metadata": {
    "customer_id": "C-001",
    "request_user": "u-12345"
  }
}
```

### 2.4 Message 结构

**Message = Agent 之间说的话**。

```json
{
  "role": "agent",  // "user" | "agent"
  "parts": [
    {
      "type": "text",
      "text": "我帮你查到了客户信息..."
    },
    {
      "type": "data",
      "data": {
        "customer_id": "C-001",
        "name": "Acme Corp",
        "ltv": 1200000
      },
      "mimeType": "application/json"
    },
    {
      "type": "file",
      "file": {
        "name": "contract.pdf",
        "uri": "https://files.company.com/contract.pdf",
        "mimeType": "application/pdf"
      }
    }
  ],
  "metadata": {
    "skill_id": "query_customer",
    "latency_ms": 250
  }
}
```

**parts 三种类型**：
- **text**：纯文本
- **data**：结构化数据（JSON）
- **file**：文件（URL 引用，不内联）

### 2.5 Artifact 结构

**Artifact = 任务完成后的"产出物"**。

```json
{
  "id": "artifact-001",
  "name": "报价单-2026-06-10.pdf",
  "description": "Acme Corp 的 2026 Q3 报价单",
  "parts": [
    {
      "type": "file",
      "file": {
        "name": "quote.pdf",
        "uri": "https://files.company.com/quotes/q001.pdf",
        "mimeType": "application/pdf",
        "size": 234567
      }
    },
    {
      "type": "text",
      "text": "报价单已生成，金额 ¥120,000"
    }
  ],
  "index": 0,
  "append": false
}
```

## 第三部分：A2A 通信模式

### 3.1 模式 1：Request/Response（同步请求）

**最简单**，类似 REST API。

```
Client Agent → POST /a2a/tasks/send → Server Agent
              ← 200 OK (Task)        ←
```

**HTTP 方法**：POST
**Content-Type**：application/json
**路径**：`/a2a/tasks/send` 或 `/a2a/message/send`

**请求体**：

```json
{
  "jsonrpc": "2.0",
  "id": "req-001",
  "method": "tasks/send",
  "params": {
    "id": "task-001",
    "message": {
      "role": "user",
      "parts": [
        { "type": "text", "text": "查一下客户 C-001 的历史订单" }
      ]
    },
    "skillId": "query_customer",
    "metadata": {
      "user_id": "u-12345",
      "tenant_id": "acme"
    }
  }
}
```

**响应**：

```json
{
  "jsonrpc": "2.0",
  "id": "req-001",
  "result": {
    "id": "task-001",
    "status": {
      "state": "completed",
      "message": "查询完成"
    },
    "artifacts": [
      {
        "id": "a-001",
        "parts": [
          {
            "type": "data",
            "data": {
              "customer": {...},
              "orders": [...]
            }
          }
        ]
      }
    ]
  }
}
```

### 3.2 模式 2：Streaming（流式响应）

**适合长任务**（>5s）。

```
Client Agent → POST /a2a/tasks/sendSubscribe → Server Agent
              ← SSE: status events + message chunks
```

**HTTP 头**：`Accept: text/event-stream`

**SSE 事件序列**：

```
event: status
data: {"state":"working","message":"查询中..."}

event: message
data: {"role":"agent","parts":[{"type":"text","text":"找到 3 个订单"}]}

event: artifact
data: {"id":"a-001","parts":[...]}

event: status
data: {"state":"completed"}
```

### 3.3 模式 3：Push Notifications（推送）

**适合异步任务**（Agent 跨天处理）。

```
1. Client 发任务，指定 webhookUrl
2. Client 立刻返回 taskId
3. Server Agent 处理中/完成后，主动 POST 到 webhookUrl
```

**请求**：

```json
{
  "jsonrpc": "2.0",
  "method": "tasks/send",
  "params": {
    "id": "task-001",
    "message": {...},
    "pushNotificationConfig": {
      "url": "https://client-agent.com/webhook",
      "auth": {
        "type": "bearer",
        "token": "secret-xxx"
      },
      "events": ["status_update", "artifact_created"]
    }
  }
}
```

### 3.4 模式 4：Multi-turn（多轮对话）

**Agent 问问题 → 用户回答 → Agent 继续**。

```
Agent: "需要更多参数：请提供客户邮箱"
   ↓ (input-required 状态)
User: "user@example.com"
   ↓
Agent: "已找到客户..."
```

**Task 状态转换**：

```json
{
  "id": "task-001",
  "status": {
    "state": "input-required",
    "message": {
      "role": "agent",
      "parts": [{"type":"text","text":"需要更多参数"}]
    }
  }
}

// 用户补充信息
{
  "jsonrpc": "2.0",
  "method": "tasks/send",
  "params": {
    "id": "task-001",  // 同一 task id
    "message": {
      "role": "user",
      "parts": [{"type":"text","text":"user@example.com"}]
    }
  }
}
```

### 4.3 A2A Controller（JSON-RPC over HTTP）

```java
package com.example.a2a;

import com.fasterxml.jackson.databind.ObjectMapper;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.MediaType;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.servlet.mvc.method.annotation.SseEmitter;

import java.io.IOException;
import java.util.*;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.Executors;

@RestController
@RequestMapping("/a2a")
public class A2aController {

    @Autowired private A2aTaskService taskService;
    @Autowired private AgentSkillRegistry skillRegistry;
    @Autowired private ObjectMapper objectMapper;

    /**
     * 获取 Agent Card（名片）
     * GET /.well-known/agent-card.json
     */
    @GetMapping(value = "/.well-known/agent-card.json", produces = MediaType.APPLICATION_JSON_VALUE)
    public ResponseEntity<AgentCard> getAgentCard() {
        return ResponseEntity.ok(skillRegistry.getAgentCard());
    }

    /**
     * JSON-RPC 入口
     * POST /a2a/rpc
     */
    @PostMapping(value = "/rpc", consumes = MediaType.APPLICATION_JSON_VALUE, produces = MediaType.APPLICATION_JSON_VALUE)
    public ResponseEntity<JsonRpcResponse> handleRpc(@RequestBody JsonRpcRequest request) {
        try {
            Object result = dispatch(request);
            return ResponseEntity.ok(JsonRpcResponse.success(request.getId(), result));
        } catch (Exception e) {
            return ResponseEntity.ok(JsonRpcResponse.error(request.getId(), -32603, e.getMessage()));
        }
    }

    /**
     * 流式响应
     * POST /a2a/rpc/stream
     */
    @PostMapping(value = "/rpc/stream", consumes = MediaType.APPLICATION_JSON_VALUE)
    public SseEmitter handleStreamRpc(@RequestBody JsonRpcRequest request) {
        SseEmitter emitter = new SseEmitter(60_000L);  // 60s timeout

        Executors.newSingleThreadExecutor().submit(() -> {
            try {
                if ("tasks/sendSubscribe".equals(request.getMethod())) {
                    // 1. 创建任务
                    A2aTask task = taskService.createOrResume(
                        request.getParams().get("id").toString(),
                        request.getParams()
                    );

                    // 2. 推送状态变化
                    taskService.executeWithStreaming(task, (eventType, data) -> {
                        try {
                            emitter.send(SseEmitter.event()
                                .name(eventType)
                                .data(objectMapper.writeValueAsString(data)));
                        } catch (IOException e) {
                            emitter.completeWithError(e);
                        }
                    });

                    emitter.complete();
                }
            } catch (Exception e) {
                emitter.completeWithError(e);
            }
        });

        return emitter;
    }

    /**
     * 路由分发
     */
    private Object dispatch(JsonRpcRequest request) {
        return switch (request.getMethod()) {
            case "tasks/send" -> handleTaskSend(request);
            case "tasks/get" -> taskService.get(request.getParams().get("id").toString());
            case "tasks/cancel" -> taskService.cancel(request.getParams().get("id").toString());
            case "agent/card" -> skillRegistry.getAgentCard();
            default -> throw new IllegalArgumentException("Unknown method: " + request.getMethod());
        };
    }

    private A2aTask handleTaskSend(JsonRpcRequest request) {
        String taskId = request.getParams().get("id").toString();
        A2aTask task = taskService.createOrResume(taskId, request.getParams());
        return taskService.executeSync(task);
    }
}
```

### 4.4 Agent Skill 注册中心

```java
package com.example.a2a;

import java.util.*;
import java.util.concurrent.ConcurrentHashMap;

@Component
public class AgentSkillRegistry {

    private final Map<String, AgentSkill> skills = new ConcurrentHashMap<>();
    private AgentCard agentCard;

    @PostConstruct
    public void init() {
        // 注册所有 Skill
        register(QueryCustomerSkill.class);
        register(GenerateQuoteSkill.class);
        register(AnalyzeContractSkill.class);

        // 构建 Agent Card
        this.agentCard = AgentCard.builder()
            .name("企业销售 Agent")
            .description("专业的销售支持 Agent，能查 CRM、生成报价、分析合同")
            .url("https://sales-agent.company.com")
            .version("1.2.0")
            .provider(AgentCard.Provider.builder()
                .organization("ACME Corp")
                .url("https://acme.com")
                .build())
            .skills(skills.values().stream().map(AgentSkill::toSkillDescriptor).toList())
            .authentication(AgentCard.Authentication.builder()
                .type("oauth2")
                .authorizationUrl("https://sales-agent.company.com/oauth/authorize")
                .tokenUrl("https://sales-agent.company.com/oauth/token")
                .scopes(List.of("read:customer", "write:quote"))
                .build())
            .capabilities(AgentCard.Capabilities.builder()
                .streaming(true)
                .pushNotifications(true)
                .stateTransitionHistory(true)
                .build())
            .defaultInputModes(List.of("text", "file"))
            .defaultOutputModes(List.of("text", "file", "json"))
            .build();
    }

    public <T extends AgentSkill> void register(Class<T> skillClass) {
        T skill = applicationContext.getBean(skillClass);
        skills.put(skill.id(), skill);
    }

    public AgentCard getAgentCard() {
        return agentCard;
    }

    public AgentSkill getSkill(String id) {
        return skills.get(id);
    }
}
```

### 4.5 Skill 抽象（实现类）

```java
package com.example.a2a;

public interface AgentSkill {

    /** Skill ID */
    String id();

    /** Skill 名称 */
    String name();

    /** Skill 描述（给 LLM 看，决定何时调用）*/
    String description();

    /** JSON Schema：输入参数 */
    Map<String, Object> inputSchema();

    /** JSON Schema：输出参数 */
    Map<String, Object> outputSchema();

    /** 执行逻辑 */
    SkillResult execute(SkillContext ctx) throws Exception;

    default SkillDescriptor toSkillDescriptor() {
        return new SkillDescriptor(id(), name(), description(), inputSchema(), outputSchema());
    }
}

public record SkillContext(
    String taskId,
    String userId,
    String tenantId,
    Map<String, Object> params,
    Map<String, Object> metadata
) {}

public record SkillResult(
    String status,  // completed / failed / input-required
    List<Part> outputParts,
    String errorMessage
) {
    public static SkillResult success(List<Part> parts) {
        return new SkillResult("completed", parts, null);
    }
    public static SkillResult needMoreInfo(String question) {
        return new SkillResult("input-required",
            List.of(new Part("text", question, null, null, null)),
            null);
    }
}
```

### 4.6 第一个 Skill：查询客户

```java
package com.example.a2a.skill;

import com.example.a2a.*;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Component;

import java.util.*;

@Component
public class QueryCustomerSkill implements AgentSkill {

    @Autowired private CustomerService customerService;

    @Override
    public String id() { return "query_customer"; }

    @Override
    public String name() { return "查询客户信息"; }

    @Override
    public String description() { return "根据客户 ID 或姓名查询客户档案、历史订单、合同信息"; }

    @Override
    public Map<String, Object> inputSchema() {
        return Map.of(
            "type", "object",
            "properties", Map.of(
                "customer_id", Map.of("type", "string", "description", "客户 ID"),
                "customer_name", Map.of("type", "string", "description", "客户姓名（与 ID 二选一）"),
                "include_orders", Map.of("type", "boolean", "default", true),
                "include_contracts", Map.of("type", "boolean", "default", false)
            ),
            "required", List.of()  // customer_id 和 customer_name 二选一
        );
    }

    @Override
    public Map<String, Object> outputSchema() {
        return Map.of(
            "type", "object",
            "properties", Map.of(
                "customer", Map.of("type", "object"),
                "orders", Map.of("type", "array"),
                "contracts", Map.of("type", "array")
            )
        );
    }

    @Override
    public SkillResult execute(SkillContext ctx) throws Exception {
        // 1. 参数校验
        String customerId = (String) ctx.params().get("customer_id");
        String customerName = (String) ctx.params().get("customer_name");
        boolean includeOrders = (boolean) ctx.params().getOrDefault("include_orders", true);
        boolean includeContracts = (boolean) ctx.params().getOrDefault("include_contracts", false);

        if (customerId == null && customerName == null) {
            return SkillResult.needMoreInfo("需要提供 customer_id 或 customer_name");
        }

        // 2. 查 CRM
        Customer customer;
        if (customerId != null) {
            customer = customerService.findById(customerId, ctx.tenantId());
        } else {
            customer = customerService.findByName(customerName, ctx.tenantId())
                .orElseThrow(() -> new RuntimeException("客户不存在"));
        }

        // 3. 组装结果
        Map<String, Object> result = new HashMap<>();
        result.put("customer", customer);
        if (includeOrders) {
            result.put("orders", customerService.findOrders(customer.getId()));
        }
        if (includeContracts) {
            result.put("contracts", customerService.findContracts(customer.getId()));
        }

        // 4. 返回 A2A 格式
        Part dataPart = new Part("data", null, result, null, "application/json");
        Part textPart = new Part("text", "已找到客户 " + customer.getName(), null, null, null);
        return SkillResult.success(List.of(textPart, dataPart));
    }
}
```

### 4.7 任务执行引擎

```java
package com.example.a2a;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

import java.util.*;
import java.util.concurrent.*;
import java.util.function.BiConsumer;

@Service
public class A2aTaskService {

    @Autowired private AgentSkillRegistry skillRegistry;
    private final Map<String, A2aTask> taskStore = new ConcurrentHashMap<>();
    private final ExecutorService executor = Executors.newFixedThreadPool(20);

    /**
     * 创建或恢复任务
     */
    public A2aTask createOrResume(String taskId, Map<String, Object> params) {
        A2aTask task = taskStore.computeIfAbsent(taskId, id -> {
            A2aTask t = new A2aTask();
            t.setId(id);
            t.setContextId(UUID.randomUUID().toString());
            t.setHistory(new ArrayList<>());
            t.setArtifacts(new ArrayList<>());
            t.setMetadata(new HashMap<>());
            t.setStatus(new TaskStatus("created", null, new Date().toString()));
            return t;
        });
        return task;
    }

    /**
     * 同步执行
     */
    public A2aTask executeSync(A2aTask task) {
        updateStatus(task, "working", "开始处理");

        try {
            // 1. 从 params 提取 skillId 和 message
            String skillId = (String) ((Map) task.getMetadata().get("params")).get("skillId");
            Message message = (Message) ((Map) task.getMetadata().get("params")).get("message");

            // 2. 解析参数（从 message.parts.data 提取）
            Map<String, Object> skillParams = extractParams(message, skillId);

            // 3. 查 Skill
            AgentSkill skill = skillRegistry.getSkill(skillId);
            if (skill == null) {
                throw new RuntimeException("Skill not found: " + skillId);
            }

            // 4. 执行
            SkillContext ctx = new SkillContext(
                task.getId(),
                (String) task.getMetadata().get("user_id"),
                (String) task.getMetadata().get("tenant_id"),
                skillParams,
                task.getMetadata()
            );
            SkillResult result = skill.execute(ctx);

            // 5. 更新任务状态
            if ("completed".equals(result.status())) {
                Artifact artifact = new Artifact();
                artifact.setId("a-" + UUID.randomUUID().toString().substring(0, 8));
                artifact.setName(skill.name() + " 的结果");
                artifact.setParts(result.outputParts());
                task.getArtifacts().add(artifact);
                updateStatus(task, "completed", "任务完成");
            } else if ("input-required".equals(result.status())) {
                updateStatus(task, "input-required", "需要更多输入");
            } else if ("failed".equals(result.status())) {
                updateStatus(task, "failed", result.errorMessage());
            }
        } catch (Exception e) {
            updateStatus(task, "failed", e.getMessage());
        }

        return task;
    }

    /**
     * 流式执行
     */
    public void executeWithStreaming(A2aTask task, BiConsumer<String, Object> emitter) {
        // 1. 推送 working 状态
        emitter.accept("status", Map.of("state", "working", "message", "处理中..."));

        // 2. 异步执行 + 推送进度
        CompletableFuture.runAsync(() -> {
            A2aTask result = executeSync(task);

            // 3. 推送 artifact
            if (result.getArtifacts() != null) {
                for (Artifact artifact : result.getArtifacts()) {
                    emitter.accept("artifact", artifact);
                }
            }

            // 4. 推送最终状态
            emitter.accept("status", Map.of("state", result.getStatus().getState()));
        }, executor);
    }

    public A2aTask get(String taskId) {
        return taskStore.get(taskId);
    }

    public A2aTask cancel(String taskId) {
        A2aTask task = taskStore.get(taskId);
        if (task != null) {
            updateStatus(task, "canceled", "已取消");
        }
        return task;
    }

    private void updateStatus(A2aTask task, String state, String message) {
        task.setStatus(new TaskStatus(state, message, new Date().toString()));
        task.getHistory().add(new Message("agent", ...));
    }
}
```

```java
package com.example.a2a.client;

import com.fasterxml.jackson.databind.ObjectMapper;
import org.springframework.http.*;
import org.springframework.stereotype.Component;
import org.springframework.web.client.RestClient;
import org.springframework.web.servlet.mvc.method.annotation.SseEmitter;

import java.util.*;
import java.util.function.Consumer;

@Component
public class A2aClient {

    private final RestClient restClient = RestClient.create();
    private final ObjectMapper objectMapper = new ObjectMapper();

    /**
     * 1. 发现远端 Agent（拿 Agent Card）
     */
    public AgentCard discover(String agentUrl) {
        return restClient.get()
            .uri(agentUrl + "/.well-known/agent-card.json")
            .retrieve()
            .body(AgentCard.class);
    }

    /**
     * 2. 同步调用 Skill
     */
    public A2aTask callSkill(String agentUrl, String taskId, String skillId,
                              Map<String, Object> params, String userId, String tenantId) {
        // 构造 JSON-RPC 请求
        Map<String, Object> request = Map.of(
            "jsonrpc", "2.0",
            "id", UUID.randomUUID().toString(),
            "method", "tasks/send",
            "params", Map.of(
                "id", taskId,
                "skillId", skillId,
                "message", Map.of(
                    "role", "user",
                    "parts", List.of(
                        Map.of("type", "data", "data", params, "mimeType", "application/json")
                    )
                ),
                "metadata", Map.of(
                    "user_id", userId,
                    "tenant_id", tenantId
                )
            )
        );

        // 发送请求
        JsonRpcResponse response = restClient.post()
            .uri(agentUrl + "/a2a/rpc")
            .contentType(MediaType.APPLICATION_JSON)
            .body(request)
            .retrieve()
            .body(JsonRpcResponse.class);

        return objectMapper.convertValue(response.getResult(), A2aTask.class);
    }

    /**
     * 3. 流式调用
     */
    public void callSkillStreaming(String agentUrl, String taskId, String skillId,
                                    Map<String, Object> params,
                                    Consumer<A2aStreamEvent> onEvent) {
        // 构造请求
        Map<String, Object> request = Map.of(
            "jsonrpc", "2.0",
            "id", UUID.randomUUID().toString(),
            "method", "tasks/sendSubscribe",
            "params", Map.of(
                "id", taskId,
                "skillId", skillId,
                "message", Map.of(...)
            )
        );

        // SSE 流式消费
        restClient.post()
            .uri(agentUrl + "/a2a/rpc/stream")
            .contentType(MediaType.APPLICATION_JSON)
            .accept(MediaType.TEXT_EVENT_STREAM)
            .body(request)
            .retrieve()
            .bodyToFlux(String.class)
            .filter(s -> s.startsWith("data:"))
            .map(s -> s.substring(5).trim())
            .subscribe(sse -> {
                try {
                    A2aStreamEvent event = objectMapper.readValue(sse, A2aStreamEvent.class);
                    onEvent.accept(event);
                } catch (Exception e) {
                    // log
                }
            });
    }
}

record A2aStreamEvent(String event, Object data) {}
```

```java
@Service
public class SmartOrchestratorAgent {

    @Autowired private ChatClient llm;
    @Autowired private A2aClient a2aClient;
    @Autowired private AgentRegistry localRegistry;

    /**
     * 主 Agent：接到任务后，自动发现并调别的 Agent
     */
    public String handleTask(String userQuery) {
        // 1. 列出已知的远端 Agent
        List<AgentCard> availableAgents = discoverAllAgents();

        // 2. 让 LLM 决定调哪个 Agent 的哪个 Skill
        String agentSelection = llm.prompt()
            .system("""
                你是一个任务调度 Agent。
                根据用户问题，从可用的 Agent 列表中选择最合适的 Agent 和 Skill。
                如果没有合适的 Agent，回复 "no_match"。
                """)
            .user("用户问题：" + userQuery + "\n\n可用 Agent：\n" +
                formatAgentList(availableAgents))
            .call()
            .content();

        // 3. 解析 LLM 的决策
        AgentChoice choice = parseAgentChoice(agentSelection);
        if (choice == null) {
            return "当前没有 Agent 能处理这个问题";
        }

        // 4. 调用远端 Agent
        A2aTask result = a2aClient.callSkill(
            choice.agentUrl(),
            "task-" + UUID.randomUUID().toString().substring(0, 8),
            choice.skillId(),
            choice.params(),
            "u-12345",
            "acme"
        );

        // 5. 整合结果 + 回答用户
        return llm.prompt()
            .system("整合 Agent 返回的结果，用自然语言回答用户")
            .user("用户问题：" + userQuery + "\n\nAgent 结果：" + formatResult(result))
            .call()
            .content();
    }

    private List<AgentCard> discoverAllAgents() {
        List<AgentCard> agents = new ArrayList<>();
        // 1. 从配置中心拿 Agent 列表
        List<String> agentUrls = configService.getAgentUrls();
        for (String url : agentUrls) {
            try {
                agents.add(a2aClient.discover(url));
            } catch (Exception e) {
                log.warn("Failed to discover agent: {}", url, e);
            }
        }
        return agents;
    }
}
```

## 写在最后

**A2A 不是"新框架"，是"新协议"**。

它的价值不在于"实现多 Agent 协作"（这个 LangGraph 也能做），而在于**"跨厂商、跨语言、跨框架的 Agent 协作标准"**。

**3 条未来 3 年的判断**：

1. **2026-2027 年 A2A 会成为"事实标准"**——所有主流 Agent 框架（LangChain / Spring AI / Dify / Coze）都会原生支持
2. **企业内部"Agent 市场"会出现**——就像 npm / pip 一样，发布 Agent Card 给别的部门用
3. **"Agent 互操作"会成为新的基础设施层**——就像 TCP/IP 之于互联网

**Java 工程师的视角**：
- A2A 协议 = 你以前写的 OpenFeign / gRPC 之于微服务
- 唯一区别：对方不是"服务"，是"智能体"
- **别等"完美协议"——A2A 现在就是事实标准，现在就用**
